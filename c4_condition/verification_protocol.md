# C4 条件条文核对协议 (2026-09-01)

目的: 为第四对照条件(C4, 只喂规范条文原文、不喂答案解析)确认每题的条文文本。

## 材料来源
- 候选切片: RAGFlow「标准规范知识库」(7,364 文档), 检索限定在题目引用的规范 PDF 内
  (scripts_repro/fetch_clause_candidates.py 第一轮; scripts_repro/refetch_hard95.py 第二轮增强)
- 核对工具: docs/paper/review/clause_review.html (人工) + AI 辅助逐题判断(本协议)

## 判定标准
1. 切片必须来自被引规范书本身(检索已按文档 ID 限定)
2. 切片须包含被引条文/表格的实质内容(数值界限、分类标准、计算式), 使一名工程师
   仅凭该文本即可作答; 仅有条号提及而无内容的不算
3. 优先正文条款/表格; 规范"条文说明"(官方释义)可接受, 在 note 里标注 shuoming
4. 剔除: 目录、前言、出版信息、征订页; 任何含答案导向表述的文本
5. 同一表格被切开时允许拼接多个切片, note 标注 merged
6. 无法恢复的题 → status=excluded + 原因, 从 C4 评测中剔除并在论文中报告数量

## 核对责任与留档
- 执行: 大模型辅助逐题判断, 全部判决与所选文本存 clause_confirmed.json
- 抽查: 对自动预选与 AI 判决按 ≥10% 抽样人工复核(作者)
- 论文披露口径: 条文文本经 AI 辅助核对并人工抽查, 核对协议与全部记录随代码公开
